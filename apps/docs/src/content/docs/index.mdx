## Install

```bash
npm install @spark-connect-js/node
```

## Your first query

```ts
import { connect } from "@spark-connect-js/node";

const session = connect("sc://localhost:15002");

const df = session.sql("SELECT 1 AS n");
const rows = await df.collect();

console.log(rows); // [{ n: 1 }]

await session.stop();
```
