## Want something that is not here?

Open an issue on [GitHub](https://github.com/prustic/spark-connect-js/issues). If the runtime or framework has a stable gRPC and Arrow story, an adapter is usually small. Additional runtime and framework integrations are on the [roadmap](/spark-connect-js/roadmap/) for 0.9.0; managed platform connectors (Databricks, AWS EMR, possibly more) land in 0.8.0.
